# TicTacToe

A console-based Tic-Tac-Toe game built with C# and .NET, featuring both human and computer gameplay modes. The project demonstrates core programming concepts such as game loops, user input validation, board management, AI decision-making, and separation of UI and game logic.

## Features

- Play against the computer
- Two game modes:
  - **Easy Mode** – Computer makes random moves
  - **Difficult Mode** – Computer uses the Minimax algorithm for optimal play
- Input validation for user moves
- Automatic win and draw detection
- Clear console-based game board display
- Structured separation between UI, game logic, and application constants

## Project Structure

```text
Program.cs         - Application entry point and game loop
UIMethods.cs       - User interface and console interactions
LogicMethod.cs     - Game rules, board logic, and AI implementation
TTTConstants.cs    - Shared constants and game configuration
```

## Technologies

- C#
- .NET
- Console Application

## How to Run

1. Open the solution in Visual Studio.
2. Build the project.
3. Run the application.
4. Select a game mode and start playing.
